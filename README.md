


# AutoSheetLocker

**AutoSheetLocker** é uma aplicação desktop desenvolvida em Python que automatiza a proteção de planilhas Excel (.xlsx) com senha. Com uma interface simples e amigável, permite proteger dezenas ou centenas de arquivos de uma só vez, eliminando o trabalho manual e garantindo a segurança dos seus dados.

## ✨ **Principais recursos:**
- Protege planilhas automaticamente com senha
- Suporta múltiplos arquivos de uma pasta
- Interface gráfica simples e intuitiva (Tkinter)
- Barra de progresso para acompanhar o andamento
- Mensagens de status e relatórios de erros
- Ideal para pequenas e grandes quantidades de arquivos

## 🚀 **Como usar:**
1. Execute o programa (`AutoSheetLocker.exe` ou `main.py` se usar o código fonte).
2. Clique em **Selecionar** para escolher a pasta onde estão suas planilhas.
3. Digite a **senha de proteção**.
4. Clique em **Proteger Planilhas** e aguarde o processo.
5. Pronto! Suas planilhas estarão protegidas com a senha informada.
